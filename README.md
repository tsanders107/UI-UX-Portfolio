# Taylor Sanders – UI/UX Portfolio

Keep all files in one folder and open `index.html` in a browser.

## Adding a project
1. Put your image in an `images/` folder (create it next to `index.html`).
2. Open `projects.js` and copy one `{ ... }` block inside the `projects` array (keep a comma between blocks).
3. Fill in `title`, `role`, `description`, `image` (e.g. `"images/my-app.png"`) and `link`.
4. Save and refresh. Cards alternate left/right automatically.

## Other things to personalize
- Email / LinkedIn / Behance links: bottom of `index.html`
- Resume: add `resume.pdf` next to `index.html`
- Colors: variables at the top of `styles.css`
